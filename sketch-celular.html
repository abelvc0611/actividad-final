Documentación del Wireframe Mobile First

El diseño de este sitio sigue la metodología Mobile First, priorizando la experiencia en pantallas pequeñas antes de adaptar la interfaz a escritorios.

La estructura móvil distribuye los contenidos de forma vertical en una sola columna con cajas independientes (burbujas) para evitar la sobrecarga visual y facilitar la interacción táctil.

Boceto Estructural

Principios aplicados:

1. Menú Vertical Apilado: Botones táctiles amplios para una selección precisa con el pulgar.

2. Bloques Aislados: Contenido dividido en burbujas con sombras ligeras para marcar jerarquía visual.

3. Tipografía Escalable: Tamaños en rem para garantizar lecturabilidad continua.
